# Home Credit 信用评分卡项目报告

> 用 30 万条真实贷款申请数据,从零构建一套可解释的申请评分卡(A 卡)。
> 全流程纯 `numpy / pandas / scipy` 实现,不依赖 scikit-learn。

---

## 1. 项目背景

| 项目 | 说明 |
|---|---|
| 业务目标 | 预测借款人的违约概率,输出 0–1000 的信用评分,用于准入与额度决策 |
| 数据来源 | Kaggle — *Home Credit Default Risk*(公开竞赛数据) |
| 样本规模 | 307,511 条贷款申请 × 122 个字段 |
| 标签定义 | `TARGET = 1` 表示客户出现还款困难(逾期) |
| 违约率 | **8.07%**(24,825 / 307,511),典型的不平衡样本 |

---

## 2. 数据清洗与特征工程

### 2.1 清洗步骤

1. **删除高缺失列**:缺失率 > 50% 的 41 列直接剔除(如 `COMMONAREA_*`、`NONLIVINGAPARTMENTS_*`),剩余 81 列。
2. **异常值处理**:`DAYS_EMPLOYED = 365243` 是系统缺失标记,共 55,374 条,统一置为缺失。
3. **极端值截尾**:所有数值特征按 1% / 99% 分位截尾(Winsorize),避免收入 1.17 亿这类极端值带偏模型。
4. **缺失填充**:数值特征取中位数;类别特征填 `MISSING`。

### 2.2 特征衍生(7 个)

| 衍生特征 | 业务含义 |
|---|---|
| `AGE_YEARS` | 年龄(由 `DAYS_BIRTH` 换算) |
| `EMPLOYED_YEARS` | 工作年限 |
| `CREDIT_INCOME_RATIO` | 贷款额 / 收入 —— 杠杆率 |
| `ANNUITY_INCOME_RATIO` | 月供 / 收入 —— 还款压力 |
| `CREDIT_TERM` | 月供 / 贷款额 —— 贷款期限代理变量 |
| `INCOME_PER_PERSON` | 人均收入 —— 家庭负担 |
| `EXT_SOURCE_MEAN` | 三个外部评分的均值 |

---

## 3. WOE / IV 特征分析(评分卡核心)

对每个特征做**分箱**(数值变量 10 分位分箱,类别变量保留高频类并合并小类),再计算
**WOE(证据权重)** 与 **IV(信息值)**。

IV 判读标准:> 0.3 强;0.1–0.3 中等;0.02–0.1 弱。

### 3.1 IV Top 10

| 排名 | 特征 | IV | 类型 | 解读 |
|---|---|---|---|---|
| 1 | EXT_SOURCE_MEAN | **0.5405** | 数值 | 外部信用评分均值,最强单变量 |
| 2 | EXT_SOURCE_3 | 0.3137 | 数值 | 外部评分 3 |
| 3 | EXT_SOURCE_2 | 0.3062 | 数值 | 外部评分 2 |
| 4 | CREDIT_TERM | 0.1325 | 数值 | 月供/贷款额,期限越长风险越高 |
| 5 | DAYS_EMPLOYED | 0.1071 | 数值 | 工作年限 |
| 6 | EMPLOYED_YEARS | 0.1067 | 数值 | 工作年限(衍生) |
| 7 | AMT_GOODS_PRICE | 0.0915 | 数值 | 商品价格 |
| 8 | DAYS_BIRTH | 0.0842 | 数值 | 年龄 |
| 9 | AGE_YEARS | 0.0841 | 数值 | 年龄(衍生) |
| 10 | OCCUPATION_TYPE | 0.0715 | 类别 | 职业类型 |

> 说明:外部评分(`EXT_SOURCE`)贡献了绝大部分区分度,这是该数据集最著名的结论;
> 业务上也成立 —— 已有征信评分本身就是最强的风险信号。

### 3.2 特征筛选

- **IV ≥ 0.02**:保留 34 个特征
- **相关性剔除**(|ρ| > 0.85):保留 **27 个特征** 进入建模
  (例如 `DAYS_EMPLOYED` 与 `EMPLOYED_YEARS`、`DAYS_BIRTH` 与 `AGE_YEARS` 高度相关,只留一个)

## 4. 模型:逻辑回归评分卡

| 项目 | 设置 |
|---|---|
| 模型 | 逻辑回归(评分卡标准模型,可解释) |
| 求解器 | IRLS(牛顿-拉夫逊法,自实现) |
| 正则化 | L2,λ = 1.0 |
| 类别不平衡 | 正样本权重 11.38(负:正 ≈ 11.4:1) |
| 训练/验证 | 70% / 30% 分层抽样(215,257 / 92,254) |

### 4.1 模型性能

| 指标 | 训练集 | 验证集 |
|---|---|---|
| **AUC** | 0.7440 | **0.7375** |
| **KS** | 0.3645 | **0.3564** |

> 参考:Kaggle 上该赛题的逻辑回归基线通常 AUC 0.74–0.76,本模型处于合理水平。
> 训练/验证差距 < 0.01,说明**没有明显过拟合**。

## 5. 标准评分卡

### 5.1 刻度设定

| 参数 | 取值 |
|---|---|
| 基准分 | 600 分 |
| 基准好坏比 | 50:1(good:bad) |
| PDO(翻倍分) | 50 分 |

换算公式:

```
score = OFFSET - FACTOR × (intercept + Σ coef_i × WOE_i)
FACTOR = PDO / ln(2) ≈ 72.13
OFFSET = 600 + FACTOR × ln(50) ≈ 882.1
```

## 6. 业务解释

1. **外部评分是核心**:`EXT_SOURCE_MEAN` 单独 IV 达 0.54,超过其他所有变量之和的贡献量级。
   这说明"历史征信表现"是最强预测因子,与风控实务一致。
2. **还款压力 > 收入水平**:`CREDIT_TERM`(月供/贷款额)IV 达 0.13,比单纯收入更有区分度 ——
   贷款期限越长、月供占比越高,违约风险越大。
3. **稳定性重要**:工作年限、年龄、手机号最近变更时间(`DAYS_LAST_PHONE_CHANGE`)都进入模型,
   反映"生活稳定性"与违约负相关。
4. **可解释性**:每个特征每个分箱都有明确的分数加减,业务人员可以直接解释"为什么这个客户被拒" ——
   这是评分卡相对黑盒模型的最大优势。
